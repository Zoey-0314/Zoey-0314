## 🚀 Recent Projects

### 🔵 CADCheckTool

**C# · .NET Framework · AutoCAD .NET API**

An engineering-oriented AutoCAD checking and automation tool. It analyzes drawing layouts, BOM information, standard parts and drawing rules, with a focus on turning repetitive CAD review work into a reproducible automated workflow.

[View repository](https://github.com/Zoey-0314/CADCheckTool_1)

### 🔵 Dayforge

**Tauri 2 · React · TypeScript · SQLite**

A lightweight Windows desktop productivity companion built around visible progress. It combines to-do tasks, habit check-ins, focus sessions, sleep records and an EXP system into a compact GitHub-style activity heatmap.

[View repository](https://github.com/Zoey-0314/Dayforge)

### 🔵 Elevator Brand Website

**Next.js · React · TypeScript · Supabase · Vercel**

An international-facing B2B elevator website designed for European and North American visitors, including product and solution pages, a database-backed inquiry workflow, protected administration, validation, anti-abuse measures and deployment infrastructure.

[View repository](https://github.com/Zoey-0314/elevator-brand-website)
